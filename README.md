# Mochi Tennis Club

A small tennis game with toy poodles. Play against the computer or against a friend.

A game by [taymcquaya](https://x.com/TayMcQuaya).

## What is in here

- `public/index.html` is the whole game in one file. Open it in a browser and practice against the computer works right away.

## Status

- Practice against the computer: works.
- Playing a friend online: not from this copy yet. The server that connects two players is the next thing to be added.
